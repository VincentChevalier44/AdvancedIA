# Regression locks

Rule: a problem that has been fixed must never come back. Each lock is a test that rebuilds the situation seen in a
driver's log (same timings and values as far as the test fixture allows) and fails on the old behaviour. Each one
has at least one mutation in `tests/mutate.py` that undoes the fix and must be detected by its lock.

Tests live in `tests/locks163.lua` (loaded by `tests/extended.lua`).
